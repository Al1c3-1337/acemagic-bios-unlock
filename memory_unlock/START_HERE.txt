RX16 RAM underclock test v0.2 -- A-004 BIOS only

The advanced-menu unlock already succeeded. This is a separate test for the
RAM timing switch that returns to Auto.

Finding
The manufacturer's OemSyncCBSSetup driver forces the AMD timing switch back
to Auto when the manufacturer's separate timing switch is Auto. It leaves
the target speed alone in that case. This matches the behavior you reported.
Both sets of controls must agree. If the speeds already match, the driver
does not necessarily enable the AMD switch, so follow BOTH save steps below.

What this tool does
It temporarily exposes the manufacturer's Memory Configuration page through
the original BIOS interface and allows entering a target down to 3200 MT/s.
You choose and save the settings yourself using the BIOS's own save function.
The app does not flash a ROM, automatically save settings, disable security,
or change timings or voltages. The menu changes disappear on reboot.

Status and risk
The exact A-004 firmware, menu structure, and generated EFI binary were
checked offline. Saving and booting this RAM configuration are NOT yet
verified on your machine. Even an underclock can prevent memory training
and boot. Removing the USB does not undo a setting you saved. Recovery from
failed training is not guaranteed; no RX16-specific recovery procedure has
been established in this work.

USB preparation
1. Use a FAT32 USB as with the successful menu-unlock test.
2. Copy the CONTENTS of this folder to its root, so it contains:
       EFI\BOOT\BOOTX64.EFI
       RX16Memory.efi
   Keep a copy of your previous USB files before replacing a same-name file.
3. Boot the USB's UEFI entry. Alternatively run RX16Memory.efi from the same
   EFI shell you used before. No startup script or echo command is needed.

First save: manufacturer's controls
4. The tool records both sets of current RAM values in RX16_RAM_LOG.txt.
   Press M to prepare the memory page, then O to open it.
   The tool stops if its firmware or menu checks fail.
5. In Memory Configuration, set:
       Active Memory Timing Settings = Enabled
       Memory Target Speed = 3200
   The number is in MT/s. Use Enter or the BIOS +/- controls to change it.
   If the BIOS opens on Main, select the Memory Configuration tab. This
   temporarily replaces Advanced for this boot.
6. Save and Exit using the BIOS's own command (normally F10).
   Leave timings and voltages unchanged. Do not load BIOS defaults.

Second save: AMD controls
7. Reboot into the regular BIOS. Its usual Advanced tab should be back.
8. Open the path you previously used:
   AMD CBS > UMC Common Options > DDR Options > DDR Timing Configuration
   > Accept
9. Set Active Memory Timing Settings = Enabled again, and confirm Memory
   Target Speed = 3200. Save and Exit again.

Check the result
10. In CPU-Z's Memory tab, DDR5-3200 should show DRAM Frequency around
    1600 MHz. Around 2400 MHz means it is still running at DDR5-4800.
    The SPD tab's rated speed is not a measurement of the current speed.
11. Reboot once more and check that Enabled remains selected and the actual
    speed remains reduced. Allow the firmware to finish memory training.

If it still reverts or the speed is unchanged
Boot this USB again. It logs both saved values before making any menu change.
At the M prompt, press another key to exit without applying the menu edits.
Send RX16_RAM_LOG.txt from the USB root and report the CPU-Z Memory-tab
frequency. The log is replaced each time the tool starts; copy it first
if you want to keep an earlier run.

If O does not open the page
Use Q and choose Enter Setup in the same boot, then Memory Configuration.
If the fields are missing, grayed out, or give an error, stop and send the
log rather than selecting another setting.

Return to automatic RAM settings while the system can still boot
Use this tool to set the manufacturer's Active Memory Timing Settings back
to Auto and save. Also set the AMD timing switch to Auto. Avoid loading all
BIOS defaults because that may hide the advanced menus again.

Keys
M = temporarily prepare memory page
O = open original BIOS memory page
V = log current saved values again
Q = return to boot menu with temporary page available for this boot
R = restore original menu definitions (does not undo saved RAM settings)

Source files and checksums are included. This package contains no ROM image
and is not an AFU flashing package.
